二、 实验内容

1. 算法原理

朴素贝叶斯分类器的实现基于贝叶斯定理和特征条件独立性假设。对于给定的待分类样本 X = (x1, x2, ..., xn)，算法需要计算其属于每个类别 ck 的后验概率 P(ck | x)，并选择后验概率最大的类别作为预测结果。

（1）贝叶斯定理与朴素贝叶斯假设：

根据贝叶斯定理，后验概率 P(ck|x) = P(x|ck)·P(ck)/P(x)。其中 P(ck) 为先验概率，P(x|ck) 为似然。朴素贝叶斯的"朴素"即假设所有特征在给定类别的条件下相互独立，即 P(x|ck) = P(x1|ck) · P(x2|ck)·...·P(xn|ck)。这一假设虽然在实际中往往不成立，但极大地简化了计算，且在文本分类等任务中表现极佳。

（2）词袋模型：

在自然语言处理中，原始文本无法直接输入数学模型，需要转换为数值特征向量。词袋模型将每封邮件表示为一个长度为 |V|（词汇表大小）的向量，其中每个维度对应词汇表中的一个单词，值为该单词在邮件中出现的次数。这种表示方法忽略了单词顺序和语法结构，仅保留词频信息，以此捕捉垃圾邮件的关键特征。

（3）多项式朴素贝叶斯：

多项式朴素贝叶斯是朴素贝叶斯在文本分类中最常用的变体。它假设特征（词频）服从多项分布。对于类别 c，单词 wi 的条件概率估计为：P(wi | c) = (count(wi, c) + α) / (∑w count(w, c) + α · |V|)。其中 α 为拉普拉斯平滑参数，用于防止训练集中未出现的单词导致零概率问题。当 α = 1 时即为标准的拉普拉斯平滑。

（4）拉普拉斯平滑：

如果在训练集中某个单词从未在垃圾邮件中出现过，那么直接使用频率估计会导致 P(wi|spam) = 0，进而使得任何包含该单词的邮件被判定为垃圾邮件的概率为 0——这显然不合理。拉普拉斯平滑通过在所有计数上加一个小的常数 α（通常为 1.0），确保每个单词在任何类别下都有一个非零的概率估计，有效缓解了数据稀疏问题。

2. 关键代码展示

本实验代码采用模块化设计，核心功能包括数据预处理、特征提取、模型训练和结果评估。

（1）数据加载与清洗：

# 加载数据并进行清洗：去空值、去重、文本标准化
def load_and_clean_data(file_path):
    df = pd.read_csv(file_path, encoding='latin-1')

    # 仅保留标签和文本两列，去除冗余信息
    df = df[['v1', 'v2']]
    df.columns = ['label', 'text']

    # 删除空值和重复样本
    df = df.dropna().drop_duplicates()

    # 标签二分类：ham:0, spam:1
    df['label'] = df['label'].map({'ham': 0, 'spam': 1})

    # 文本清洗：去除非字母字符并统一小写
    df['text'] = df['text'].apply(lambda x: re.sub(r'[^a-zA-Z ]', '', x).lower())
    
    # 数据转换为列表，方便处理
    texts = df['text'].tolist()
    labels = df['label'].tolist()

    return labels, texts

（2）数据集划分与特征提取：

通过 train_test_split 的 stratify 参数保证训练集与测试集的类别分布一致

使用了 scikit-learn 提供的 CountVectorizer 进行词袋特征提取，通过设置 stop_words 自动过滤掉 'the'、'is'、'a' 等无实际语义的停用词 

# 分层抽样划分训练集和测试集，保证类别比例一致
# 设置固定随机种子，确保结果可复现性
def split_dataset(texts, labels, test_size=0.2, random_state=42):
    X_train, X_test, y_train, y_test = train_test_split(
        texts, labels, test_size=test_size,
        random_state=random_state, stratify=labels
    )
    return X_train, X_test, y_train, y_test

# 创建词袋模型向量化器，去除英文停用词，提高分类精准度
def create_bow_features():
    vectorizer = CountVectorizer(stop_words='english')
    return vectorizer

（3）模型训练与评估：

使用 MultinomialNB 封装的多项式朴素贝叶斯算法，设置拉普拉斯平滑参数alpha=1.0 

# 使用多项式朴素贝叶斯进行训练，拉普拉斯平滑参数alpha取1.0
def train_naive_bayes(X_train, y_train):
    model = MultinomialNB(alpha=1.0)
    model.fit(X_train, y_train)
    return model

# 评估模型：输出准确率、混淆矩阵和分类报告
def evaluate_model(model, X_test, y_test):
    y_pred = model.predict(X_test)
    
    print("\n[4] 模型评估结果：")
    print(f"    准确率 (Accuracy): {accuracy_score(y_test, y_pred):.4f}")
    print("\n混淆矩阵:")
    print(confusion_matrix(y_test, y_pred))
    print("\n分类报告:")
    print(classification_report(y_test, y_pred, target_names=['正常邮件(ham)', '垃圾邮件(spam)']))

3. 创新点 & 优化

（1）数据批处理： 在数据加载阶段，在代码完成基本的 CSV 读取和分类后，调用了 dropna() 和 drop_duplicates() 有效移除了空值样本和重复样本。同时，通过正则表达式 re.sub(r'[^a-zA-Z ]', '', x) 去除了标点符号、数字等噪声字符，并将所有文本统一转换为小写，避免了同一单词因大小写不同而被视为不同特征的问题。

（2）停用词过滤： 通过调用 CountVectorizer(stop_words='english') 方法，在构建词袋模型时自动过滤了英语中常见的停用词。这些高频但无语义区分能力的词（如 "the"、"and"、"of"）如果不加过滤，会在特征空间中占据大量维度却对分类贡献甚微。去除停用词后，特征向量能够更有效地捕捉那些真正具有类别区分度的关键词。

（3）分层抽样策略： 在划分训练集和测试集时，代码调用 stratify=labels 方法进行分层抽样。由于数据集中正常邮件和垃圾邮件的样本量差异极大（ham:spam≈7:1），普通的随机划分可能导致测试集中某一类别的样本过少，从而影响训练及评估的可靠性。分层抽样确保训练集和测试集中两类的比例与原始数据集保持一致，使评估结果更具统计意义。
